# JDI 포털 데스크톱 앱

포털(https://jdiportal.com)을 브라우저 탭이 아니라 **항상 켜져 있는 사내 프로그램**처럼 쓰기 위한 껍데기 앱입니다.
Windows 작업표시줄 오른쪽 **트레이(숨겨진 아이콘)** 에 상주합니다.

## 중요: 개발은 따로 하지 않습니다

화면과 기능은 전부 웹(`jdi-portal/`)에서 불러옵니다.
**웹을 고쳐서 배포하면 이 앱에도 자동으로 반영됩니다.** 앱을 다시 만들거나 재설치할 필요가 없습니다.

이 폴더의 코드를 고쳐야 하는 경우는 트레이 메뉴·아이콘·자동 실행 같은 **껍데기 동작을 바꿀 때뿐**이며,
그때만 설치 파일을 다시 배포하면 됩니다.

## 실행 방법 (개발/시험용)

```bash
cd jdi-desktop
npm install   # 처음 한 번만
npm start
```

## 사용법

| 동작 | 결과 |
|---|---|
| 창의 X 버튼 | 종료되지 않고 **트레이로 숨김** (알림은 계속 받음) |
| 트레이 아이콘 클릭 | 창 열기 / 숨기기 전환 |
| 트레이 아이콘 우클릭 | 포털 열기 · Windows 시작 시 자동 실행 · 완전히 종료 |
| 프로그램 두 번 실행 | 창이 두 개 뜨지 않고 기존 창이 앞으로 나옴 |

로그인 상태는 앱을 껐다 켜도 유지됩니다.

## 알림

포털이 이미 실시간으로 알림을 받아 Windows 알림을 띄웁니다
(`jdi-portal/src/components/dashboard/NotificationProvider.tsx` → `src/lib/notifications/desktop.ts`).
이 앱은 크롬과 같은 엔진을 쓰므로 그 알림이 그대로 동작하며, **창을 닫아 트레이에 넣어둔 상태에서도 알림이 옵니다.**

알림을 클릭하면 숨겨진 창이 다시 나타나야 하는데, 이를 위해 웹 쪽에서 `window.jdiDesktop.showWindow()` 를
호출합니다. 이 값은 `preload.js` 가 노출하며, 일반 브라우저에는 존재하지 않으므로 그대로 무시됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.js` | 앱 본체 — 창 생성, 트레이, 자동 실행, 외부 링크 처리 |
| `preload.js` | 웹 페이지와 앱 사이의 유일한 통로 (`window.jdiDesktop`) |
| `icon.png` | 트레이·창 아이콘 (`jdi-portal/public/icon-512.png` 복사본) |

## 보안 원칙 (완화 금지)

원격 웹페이지를 로드하므로 아래 설정을 유지합니다.

- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
- `jdiportal.com` 외 주소로의 창 내 이동 차단 (외부 링크는 기본 브라우저로 열림)
- 알림(notifications) 권한만 허용, 위치·카메라·마이크 등은 거부

## 아직 하지 않은 것 (다음 단계)

- **설치 파일(.exe) 만들기** — `electron-builder` 추가 필요. 직원 PC 배포용.
- **코드 서명** — 인증서가 없으면 설치 시 "Windows의 PC 보호" 경고가 표시됩니다.
  경고를 없애려면 코드 서명 인증서(연 수십만 원)가 필요합니다.
- **트레이 아이콘에 안 읽은 알림 개수 배지** 표시
- **껍데기 자동 업데이트** 구성
