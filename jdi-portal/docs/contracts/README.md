# 2026 TMA 인플루언서 계약서 v2

> **2026-08-31 조건 반영 완료.** 2026-08-21 곽억배 협의로 바뀐 네 가지(게시 유지 3개월 · 2차 활용 파트너십 광고 연동 2개월 · 클린본 택1 · 촬영 원본 사후 요청)를 두 계약서 본문과 개별 조건표에 모두 적용했다.
> 수정 전 원본은 `_backup/` 에 있다. 자세한 배경은 `omx_wiki/계약-조건-수정-대기.md`.

이 폴더의 Word 파일은 모두싸인 템플릿을 바꾸기 전에 검토하기 위한 운영 초안이다.

## 문서 구성

- `2026_TMA_인플루언서_광고비형_계약서_v2.docx`: 제품과 광고비를 함께 제공하는 협업
- `2026_TMA_인플루언서_순수협찬형_계약서_v2.docx`: 제품만 제공하고 별도 광고비가 없는 협업

두 문서는 다음 조건을 공통으로 사용한다.

- Instagram Reels 중심 숏폼 영상 1편
- 게시 유지 **3개월** (2026-08-21 변경, 이전 6개월)
- 2차 활용은 계약별로 무상·추가비용·불가 중 선택하며, 허용 시 시작일과 종료일을 명시
- 2차 활용 범위는 **Instagram·Meta 파트너십 광고 연동(기본)**, 자사 SNS 재게시, 발췌·컷편집·자막·로고·음악·타 영상 결합 중 선택
  - 기본은 **파트너십 광고 연동 하나뿐**이다. 게시물을 그대로 광고로 돌리는 방식이라 편집·재가공이 없다
  - 자사 SNS 재게시와 편집 활용은 **기본 범위에서 뺐다**(2026-08-21 지시). 필요하면 개별 협의한다
- 상세페이지 사용 제외
- 촬영 전 광고 사용 가능한 음원 확인
- 필수 납품 파일은 **택1**: `게시본만` / `게시본 + 자막·워터마크 없는 클린 완성본` / `없음`
  - 파트너십 광고 연동만 쓰면 게시물을 그대로 돌리므로 **클린본이 쓰이지 않는다.** 기본은 `게시본만`이다
- 촬영 원본은 무상·추가비용·미제공 중 선택하되, **기본은 `제공하지 않음`이다**
  - 미리 받으면 쓰지도 않을 원본에 돈을 내게 된다. 완성본이 좋아 별도 광고 영상을 만들고 싶을 때 **그때 요청하고 비용을 협의**한다
- 개별 조건표는 `항목 / 입력 항목 / 합의 내용 / 형식·단위` 4열 구조이며, 실제 값은 넓은 빈 셀에 입력
- 발송일·초안 전달일·게시 예정일·2차 활용 시작일·종료일·원본 전달일은 각각 독립 행으로 분리하고 `YYYY-MM-DD` 형식을 사용
- 광고비·2차 활용 추가비용·원본 추가비용도 각각 독립 행에 입력

## 모두싸인 적용 순서

1. 계약 담당자가 개별 조건표의 트리 크기, 일정, 광고비, 2차 활용, 원본 제공 조건을 확정한다.
2. `을` 입력 필드로 성명, 채널명, 연락처, 이메일, 주소, 정산정보, 서명을 배정한다.
3. 회사가 먼저 채워야 할 날짜·금액·선택칸은 발송 전에 확정한다.
   - 모두싸인 텍스트 입력 필드는 개별 조건표의 넓은 세 번째 열에 배치한다.
   - 날짜 필드는 오른쪽 `YYYY-MM-DD` 안내 문구를 가리지 않도록 빈 셀 안에서만 넓게 배치한다.
   - 계약서에 인쇄된 `□` 표시는 위치 안내용이므로 모두싸인 실제 체크박스 필드를 해당 위치에 별도로 올린다.
4. 5명 정도에게 시험 발송하고 모바일 입력·서명 흐름을 확인한 뒤 100명 운영으로 확대한다.

## 운영상 확인이 필요한 기본값

- 광고비 지급일: **게시 완료 후 7영업일 이내**(필수 납품 파일이 있는 경우 해당 파일 전달 완료 후)
- 광고비·2차 활용비·원본 제공비는 달리 명시하지 않는 한 부가세 포함 총액이며, JDI가 부가세를 별도로 추가 지급하지 않음
- 사업자는 총액을 공급가액과 부가가치세로 구분해 증빙을 발행하고, 개인은 법령상 필요한 원천징수를 적용
- 초안 검수: 갑의 의견 회신 목표 2영업일, 기본 수정 1회
- 필수 파일 전달: 게시 후 3영업일 이내
- 미게시 시 제품 반환: 요청 후 7일 이내, 을 귀책 시 반환비 부담
- 2차 활용 기간: **원칙적으로 2개월**(11~12월 크리스마스 시즌)이며 계약서에서 시작일·종료일을 모두 기입
