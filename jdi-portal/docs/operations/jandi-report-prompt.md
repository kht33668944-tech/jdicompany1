# 잔디 업무 자동 보고 — 작성 규칙

예약 루틴 `jdi-work-report` 가 평일 13시·18시에 이 문서를 읽고 그대로 실행한다.

## 절차

1. 데이터를 뽑는다. **DB 를 직접 조회하지 말고 반드시 이 스크립트를 쓴다.**

   ```bash
   cd "C:/Users/jdico/Desktop/개발/웹사이트/jdicompany/jdi-portal"
   node --env-file=.env.local scripts/jandi-report-data.mjs
   ```

2. 출력을 읽고 보고서를 쓴다(아래 "보고서 규칙").

3. 보고서를 임시 파일로 저장한 뒤 전송한다.

   ```bash
   node --env-file=.env.local scripts/jandi-report-send.mjs .tmp-jandi-msg.txt
   rm -f .tmp-jandi-msg.txt
   ```

   보낼 내용을 먼저 확인만 하려면 뒤에 `--dry-run` 을 붙인다.

`.tmp-*` 는 `.gitignore` 대상이라 커밋되지 않는다. 전송 후 지운다.

## 보고서 규칙

### 무엇을 쓰나

**직원들이 실제로 한 업무 내용만 쓴다.** 대표가 읽고 "우리 회사가 오늘 어디까지
갔는지" 알 수 있어야 한다.

- **사람별로 묶는다.** 누가 무엇을 했는지가 먼저 보여야 한다.
- **업무보고 본문을 읽고 핵심을 뽑는다.** 제목만 옮겨 적지 않는다.
- **숫자와 금액은 본문에 있는 값을 그대로 쓴다.** 반올림하거나 추정하지 않는다.
- 돈이 움직인 건(입금·출금·확정 예산·계약 금액)은 빠뜨리지 않는다.

### 무엇을 쓰지 않나

- **"대표가 결정해야 할 것" 같은 지시·제안 항목을 만들지 않는다.** 사실 보고만 한다.
- **기한이 지난 할일을 나열하지 않는다.** 데이터에는 들어오지만 보고서에 쓰지 않는다.
- 최근 4일 업무보고 제목은 **맥락 파악용**이다. 오늘 한 일처럼 쓰지 않는다.
- 데이터에 없는 내용을 지어내지 않는다. 모르면 쓰지 않는다.

### 모양

첫 줄이 제목이고, 빈 줄 다음이 본문이다.

```
📋 JDI 하루 마감 · 9월 1일(화) 18:00

김효태
코스콤 금융정보 API 개발지원비 330만원 입금을 완료했습니다(9/1 10:47). 코스콤
계약 3건 중 유일한 유상 건이며, 나머지 2건은 무상특례·청구유예 상태입니다.
후속으로 API 서비스 등록 뒤 샌드박스 API Key 를 받을 예정입니다.

이용준
혼합 트리 페이지 보완 사항을 확인·수정 중입니다(기한 오늘).

표민근
다람쥐 선금 결제와 회전트리 베이스 배송 확인을 맡고 있습니다.

📊 완료 0 · 진행 4 · 검토대기 0 · 업무보고 1건
```

- 제목: 13시는 `📋 JDI 점심 현황 · M월 D일(요일) HH:MM`, 18시는 `📋 JDI 하루 마감 · …`
- 사람 이름은 그 줄에 단독으로 둔다. 이름 아래에 문장을 쓴다.
- 한 사람당 **2~4문장**. 길어지면 대표가 안 읽는다.
- 마지막 줄의 숫자는 스크립트 출력의 "숫자 한 줄" 값을 **그대로** 옮긴다.
- 전체 길이는 넉넉잡아 1,500자 안쪽으로 맞춘다.

### 13시와 18시의 차이

| | 13시 (점심 현황) | 18시 (하루 마감) |
|---|---|---|
| 관점 | 오전에 진행된 것 + 오늘 남은 일정 | 하루 전체 |
| 업무보고 | 오전에 올라온 것만 (없으면 그 사람은 생략) | 오늘 올라온 것 전부 |

### 아무 일도 없을 때

업무보고 0건, 오늘 완료 0건이면 억지로 길게 쓰지 않는다.
진행 중인 일 위주로 세 줄 안쪽으로 짧게 쓰고 숫자 줄을 붙인다.
**아무것도 보내지 않는 선택은 하지 않는다** — 안 오는 것과 고장 난 것을 구분할 수 없다.

## 실패했을 때

- 스크립트가 DB 오류를 내면 잔디로 아무것도 보내지 말고 그대로 끝낸다.
  (오류 내용을 잔디에 올리지 않는다.)
- 전송이 실패하면 한 번만 다시 시도하고, 그래도 안 되면 끝낸다.
  다음 회차에 자연히 복구된다.

## 참고

- 서버 쪽 기계식 보고(`/api/cron/jandi-report`, Cloud Scheduler `jdi-portal-jandi-report`)는
  이 루틴과 중복되므로 **일시중지** 상태다. 이 루틴이 계속 실패하면 그쪽을 되살린다:
  `gcloud scheduler jobs resume jdi-portal-jandi-report --project jdi-portal-seoul --location asia-northeast3`
- 이 루틴은 **컴퓨터가 켜져 있고 Claude 앱이 열려 있을 때만** 실행된다.
